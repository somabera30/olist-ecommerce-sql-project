# Analysis Outputs

This folder contains selected CSV outputs generated from the customer retention analysis using PostgreSQL.

Each file represents the result of a specific analytical query and provides supporting evidence for the findings documented in the project.

| File Name | Description |
|---|---|
| `01_overall_repeat_purchasing.csv` | Customer distribution between one-time and repeat purchasers. |
| `02_time_to_second_purchase.csv` | Average, median and other statistics measuring the time taken to make a second purchase. |
| `03_first_purchase_category.csv` | Repeat purchase rates across different first-purchase product categories. |
| `04_first_purchase_basket_size.csv` | Comparison of repeat purchase rates across first-purchase basket sizes. |
| `05_delivery_experience.csv` | Delivery time comparison between one-time and repeat customers. |
| `06_first_purchase_value.csv` | Comparison of first-purchase value, item count and review scores between customer groups. |
| `07_customer_location.csv` | Geographic comparison of customer retention rates across Brazilian states. |

**Note:** These are selected analytical outputs. The corresponding SQL queries are available in the `sql/` folder.
