# Dataset

The dataset used in this project is the **Brazilian E-Commerce Public Dataset by Olist**, obtained from Kaggle.

### Data Source
- **Platform:** Kaggle
- **Dataset:** [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

### Download Instructions
1. Visit the Kaggle dataset link above.
2. Download the dataset.
3. Extract the CSV files.
4. Place the CSV files inside this `data/` directory.

### Note
The original CSV files are not included in this repository due to their large file size. Please download them directly from the source linked above.
